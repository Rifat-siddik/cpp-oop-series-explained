# OOP Basics — Procedural vs Object-Oriented

## Procedural Programming
- Code runs as a sequence of instructions/functions
- Data and functions exist separately
- Simple for small programs, but harder to scale/maintain

## Object-Oriented Programming (OOP)
- Organizes code into "objects" combining data + behavior
- Improves reusability, organization, and maintainability
- Models real-world entities more naturally
